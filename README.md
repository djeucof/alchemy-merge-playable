# 💎 Alchemy Merge
Single-file interactive HTML5/Canvas playable ad prototype.

## Key Playable Production Features
- **Zero-Friction Onboarding:** Animated hand pointer guides the first merge and reappears automatically during idle moments.
- **Short Session Pacing:** Target progression (up to 6 merges or Crown tier) leads smoothly into an End Card within ~10–20 seconds.
- **Juice & Tactile Feedback:** Squash-and-stretch spring scaling, radial shockwaves, particle bursts, micro screen-shake, combo multipliers, and procedural Web Audio SFX (no external audio assets, with mute toggle).
- **End Card & Telemetry Readout:** Displays merges completed, max combo, remaining/target moves, and active session duration alongside a pulsing CTA button and replay trigger for portfolio review.
- **Single-File Architecture:** Pure HTML, CSS, and Vanilla JS with no external dependencies.

## Live Demo
Published via GitHub Pages: `https://djeucof.github.io/alchemy-merge-playable/`

## Producer Notes
- **Hook & Clarity:** Color-coded tier progression bar (`✦ → ❖ → ◈ → ☀ → 👑`) communicates the goal immediately without walls of text.
- **Drop-off Prevention:** Auto-refill when few pieces remain prevents dead-ends before the hook completes.
- **Portfolio / Review Mode:** Includes a **Replay** button on the End Card so reviewers can test multiple runs without reloading the page.
